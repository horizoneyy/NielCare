# Pengujian Blackbox (Blackbox Tests) — NielCare Dental

Dokumentasi dan skrip pengujian blackbox untuk antarmuka pengguna dan alur API NielCare Dental.
Lihat skenario pengujian lengkap di `docs/06-testing/blackbox-test-cases.md`.

## Skenario Uji Prioritas:
1. **TC-BB-001:** Alur pendaftaran pasien baru.
2. **TC-BB-002:** Penolakan input sapaan/tes pada AI Triage (HTTP 422).
3. **TC-BB-003:** Analisis gejala darurat gigi dan pemilihan dokter bedah mulut.
4. **TC-BB-004:** Booking slot jadwal dan pencegahan slot ganda.
5. **TC-BB-005:** Konfirmasi jadwal oleh dokter gigi.
6. **TC-BB-006:** Pengisian EMR dan penyelesaian transaksi.
7. **TC-BB-008:** Pengujian batas otorisasi middleware (RBAC).
